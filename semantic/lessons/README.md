# Accepted Bootstrap Lessons

1. Physical host/repository coordinates belong to .vibe/environment.json, not duplicated as permanent Mission architecture.
2. Moving control browsers/machines may lose browser-local SemanticSession state; rehydration must be explicit and fail-closed.
3. Opera/Chromium relay integration needs explicit host access and must account for content-script isolated-world behavior.
4. PowerShell automatic variables such as $Args must not be reused as protocol argument objects.
5. Windows PowerShell 5.1 / .NET File.Replace must not depend on a null backup-path argument.
6. Standalone lifecycle scripts must contain their own required authority/path variables and must not depend on installer parent scope.
7. A copied old-machine bridge secret/runtime ledger must not silently become new-host authority.
8. Transport health, read access and mutation acceptance are separate claims and must be proven separately.

These are engineering lessons, not product requirements.
